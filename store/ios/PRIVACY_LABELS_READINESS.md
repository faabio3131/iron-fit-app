# iOS — App Privacy Labels Readiness

Status: **NOT SUBMITTED / EXTERNAL EVIDENCE REQUIRED**

This file is an engineering checklist, not a completed App Store privacy-label declaration.

Before App Store Connect submission, reconcile the production data flow against the approved Macro L register and identify:

- contact/account identifiers;
- user content and student profile data;
- health/fitness-related data actually processed;
- diagnostics/analytics actually enabled;
- financial/purchase information actually handled by IRON versus hosted providers;
- tracking, if any;
- purposes and data linkage;
- retention/deletion behavior;
- active third-party processors.

Do not infer a "Data Not Collected" or "Not Used for Tracking" answer merely from dependencies or build success.
